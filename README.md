# HIVI Tecnologia

Repositório oficial do site empresarial da **HIVI Tecnologia** — empresa de soluções tecnológicas especializada em Consultoria, Gestão de TI, Infraestrutura e Desenvolvimento Web.

---

## Sobre o Projeto

Site institucional com foco em apresentar a empresa, seus serviços, portfólio e facilitar o contato com potenciais clientes. Desenvolvido com Next.js e hospedado na Vercel, com Supabase como backend.

## Stack

- **Framework:** Next.js 14+ (App Router)
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS
- **Backend/DB:** Supabase
- **Hospedagem:** Vercel
